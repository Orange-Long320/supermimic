# 长时间左右转回旧位置排查（2026-11-04）

## 已确认的代码机制

`SkillGoal.position` 是累计参考轨迹的位置，不是每次技能切换时的实测位置。
`advance()` 积分参考水平速度和角速度；`goal()` 用该累计位置构造目标锚点，
将目标与实测锚点的位置差转到机器人坐标后交给策略。`SkillPhase.select()`
只切换参考片段及过渡队列，不重新登记转向中心。

因此，“原地转”目前表示**围绕累计参考位置转向并补偿位置误差**，并不表示
“围绕按下转向键时的实际位置转”。先前行走跟踪误差、停止偏移以及实机估计误差
都会进入后续转向的位置反馈。这不是沿已存路线倒放，也不是转向参考在请求前进。

## 实机状态链的限制

本次仿真使用模拟器 odometry 真值，不包含 IMU 积分误差。
当次实机状态生产器 `summary.json` 显示 `imu_only_zupt=true`、
`support_accepted=0`，使用 IMU 位姿充当骨盆位姿，未验证运动中的估计准确性。
纯积分和静止零速更新不能提供独立绝对位置约束；它们可能放大累计参考与实测位置差。
但目前没有该次实机的独立位置真值，不能把记录中的估计位移直接认定为漂移，
也不能由本次仿真确定实机现象中各因素的占比。
