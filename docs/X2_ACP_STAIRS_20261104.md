## 已检查的集成边界

- `envs/box_scene.py` 已支持固定箱体集合，世界模型接收最近两个箱体的 18 维特征。
  这不等于已经有楼梯高度图或 ACP。
- `policy/nets.py` 当前只有 `motion` 编码器，目标来自未来参考动作。

  尚未证明这些数据包含可用的 X2 上楼参考及匹配场景。

## 实现顺序与验收

1. 楼梯尺寸配置、碰撞几何和地形采样共用一个定义；先使用仿真地形真值。
   尺寸范围只是待测实验配置，不能称为 X2 可达范围。
2. 准备带场景、足底接触标签和来源记录的 X2 上楼示范，检查足底与踏面、关节限制
   和从平地起步的连续性。无动力学验收的 IK 或参考播放不能当作策略结果。
3. 训练接触条件控制器：观测历史、地形、双脚接触目标和终点进入策略；世界模型
   在同一楼梯几何上拟合真实物理转移；想象轨迹中每步重算地形与相对接触目标。
   同步实现接触/进度/平衡/抬脚/动作约束目标以及跌倒、非足部支撑终止。
4. 用真实物理成功轨迹监督双脚注意力规划器。使用踏面候选点的分类输出，部署
   选实际候选点，避免对不同台阶坐标求平均后落在空中。落点需要足底完整支撑
   检查，点落在踏面上本身不足以证明整只脚受支撑。
5. 将规划器接入真实采集和想象更新，逐渐减少参考动作依赖。最终评测不能输入
   示范片段 ID、未来参考姿态或参考相位。
6. 先单卡关闭编译做有界流程与显存测试，再启用世界模型和策略编译做长训。
   每次运行独立目录，保留源码、配置、种子、数据及场景 SHA256、命令、PID、GPU。

验收从平地开始，完整走上楼梯并在顶部稳定停止；记录完整任务成功率、跌倒率、
非足部支撑、足底滑移/踏空、关节/力矩越界和顶部停止表现。训练与测试的尺寸组合
分离，同时单列尺寸范围外测试；短片段或随机相位初始化成功不算完整上楼。
正式数值阈值须在首次基线评测前冻结，保留失败轨迹。
