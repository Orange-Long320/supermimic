# X2 骨盆估计误差与仿真修正（2026-11-02）

范围为服务器 CPU、隔离 ROS 仿真；无机器人连接、实机命令或 PPO。正常估计只读取 IMU、关节及显式声明的平地假设；odom 仅用于离线评分和标明的真值辅助碰撞重建。下列结果不构成实机验收。

## 漂移与接触证据

上轮 r6 约 56.8 秒，输出速度误差相对 odom 100 ms 中心差分的时间加权均值约 `[0.00056, 0.00041, -0.00339]` m/s，积分约 `[0.0319, 0.0230, -0.1923]` m；与末端 Z 约 −0.190 m 一致。超过 50 ms 的输出间隔用端点插值估计贡献约 −0.0213 m，因缺帧不能当作真实积分值。按支撑年龄分组，Z 速度误差均值在 <25 ms 各组约 −1.2 至 −3.2 mm/s，在 25–50 / 50–100 ms 分别约 −14.1 / −10.0 mm/s；年龄与动作、接触状态同时变化，不足以确定单一因果。r2 接受的 1995 次支撑观测中 1993 次与 IMU header 精确匹配，观测速度相对 odom 差分的均值 `[0.00021,0.00010,-0.00134]` m/s，逐轴 RMSE `[0.00991,0.00916,0.02071]` m/s，三维最大误差 0.546 m/s。100 ms 中心差分是平滑速度，未证明等于瞬时速度；足部撞击时平滑/瞬时差异可放大峰值，加之跨流物理采样时刻未独立同步，不能将峰值直接认作滑移或接触误判，也不能归结为已辨识传感器偏置。同一 1993 个观测以 20 ms 中心差分评分时三维最大残差为 0.163 m/s，以 100 ms 差分则为 0.546 m/s，峰值明显依赖参考平滑窗口；20 ms 也仍受采样时序限制。

官方 MuJoCo 场景为 z=0 平面。旧轨迹中，假设最低碰撞球接触已知平地、用姿态和关节 FK 单独估计相对骨盆高度，结果相对 odom 的 Z RMSE 0.00098 m、末端误差 +0.00018 m、最大绝对误差 0.00455 m。最低球相对地面的真实几何间隙中位 −0.99 mm（碰撞存在穿透），因此几何高度不是完美测量。独立诊断中以 odom 位姿和记录关节重建 MuJoCo 几何接触，2153 次被接受的支撑观测中有 2150 次最低球处于重建接触，3 次未重建出足接触；它是跨流、离线、真值辅助的碰撞重建，不是二进制仿真的原生接触事件或接触力证据。

## 修正与短轨迹对照

`--sim-flat-ground-height` 仅在显式 sim-only 支撑模式中使用。支撑接受时以最低球相对骨盆的高度与 IMU 杆臂给出相对骨盆高度约束；不读取真值，仍假定平地、至少一足接触与模型几何正确。支撑被拒绝时不伪造高度观测；超过原 100 ms 支撑有效时限仍停发。位置、速度和输出须区分。

r2 同一仿真中，两个生产者仅差有无平地高度约束。共同窗 54.81 s、共同有效网格 95.73%；平地版/无高度对照的 Z 位置 RMSE 为 0.00094/0.1268 m，末端 Z 为 −0.00324/−0.2135 m；XY 位置 RMSE 0.0244/0.0278 m。平地版最大输出间隔 142 ms，因此不代表连续输出通过。

对 r2 逐事件分析，所有 20 个 >50 ms 的输出间隔都伴随支撑超时拒绝；最长支撑接受间隔 230 ms，最长拒绝序列 190 ms（7 次双足速度不一致、3 次持时）；纯持时也出现 7 次持续约 128 ms。最低足在近同高状态交替会不断重置 40 ms 持时。修正后，如果两足接近同高且满足原速度一致条件，最低足的小幅交替保持同一支撑假设，不重置持时；真正不一致仍拒绝，原 1 cm、0.2 m/s、40 ms 和 100 ms 门限均未放宽。

r4 同场双生产者仅区别上述连续性逻辑，均启用平地高度；共同窗 53.81 s、共同有效网格 96.28%。新版/原版 XY 位置 RMSE 0.0284/0.0437 m，最大 XY 误差 0.0437/0.0665 m；Z RMSE 0.00099/0.00095 m；持时拒绝 98/379 次，支撑超时停发 39/86 次，最长输出间隔 102/162 ms。新版最长接受间隔 188 ms，最长拒绝段约 148 ms（6 次不一致、2 次持时）；旧版对应 236 ms、约 194 ms（4 次不一致、6 次持时）。新版瞬时最大 XY/Z 速度误差 0.272/0.537 m/s，受上述速度参考限制，未建立连续或实机可用性。

## 长轨迹与记录器

第一场 180 秒墙钟长测（r3，控制时间 169.13 s、8450 帧、failure=null、无重置）仍使用旧支撑连续性逻辑，平地高度版与无高度版共同窗 170.83 s、有效网格 96.23%。平地版 XY/Z 位置 RMSE 0.0404/0.000984 m，最大 XY/Z 误差 0.0669/0.00581 m，末端 Z +0.00016 m，最大输出间隔 226 ms；无高度对照 Z RMSE 0.4097 m、末端 −0.7550 m。其最大 XY 已超过 5 cm；动作执行无重置不代表物理验收。

r2 记录器异步 JSON 写入实验未能解决接收缺失：55.01 s 同场每组轻量探针约 54.6k header，新/旧记录器各约 35.4k；探针独有约 19.3–19.4k。r3 将 raw 回调与多进程解码/写入分开后，171.03 s 每组记录器从旧版约 111.2k 提升至 151.3k，但探针仍为约 168.8–169.0k，探针独有约 19.1–19.3k；队列溢出和接收后未写均为零。多路回调仍由一个 executor 分发，不能归咎于写盘，也不能把配置频率当实收。最终方案改为每路独立 ROS 订阅进程，保留逐路收写数量、失败及有界停机，等待最终同场探针对照判定。

r5 的最终方案启动失败：多层符号链接使 profile 解析超限，多个 participant 同时启动触发默认 CycloneDDS 索引容量。隔离域中清理并确认无本任务残余进程后，默认配置 14 个独立节点仅 9 个成功；只对进程设置 `MaxAutoParticipantIndex=32` 后 14/14 成功。r6 长测使用直接 canonical 链接、单场进程私有配置、domain 210，未改共享系统配置；早期未加载项目 RMW 动态库的容量测试及 r5 失败均保留原日志。
