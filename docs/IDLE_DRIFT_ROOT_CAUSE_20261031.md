首轮只读诊断：从记录的实际姿态、关节、anchor 目标与 FK 反推出参考根部 XY，末次松键后第 5～15 秒，两组参考点变化均 <4e-8 m，所有参考根部线/角速度为零。因此已排除站立阶段参考点仍在移动。原型最大偏移出现在松键约 5.94 秒；附近实测全关节速度 RMS 升至约 0.425 rad/s，晚于“松键五秒已静止”的评测假设。新方案在 +5 秒的根部参考误差约 [-0.174,-0.226] m，旧方案约 [-0.231,-0.222] m；原型误差范数并未更大，不能仅把较大漂移归因于较大 anchor 误差。
