# X2 官方仿真策略接入记录

## 来源与隔离

用户指定 X2 Ultra，版本 1.1.5。公开 AimDK 文档版本为 1.1.0，无法仅据此确认固件与 SDK 的对应，后续需以机器人自带 SDK / 厂商说明核对。使用官方 RL Deploy v1.1 扩展包中的 `lx2501_3_t2d5` 物理模拟器及消息定义，不是官方 MC 控制器。原扩展包及 SHA-256 见 `X2_DEPLOYMENT.md`。官方舞蹈配置只使用 29 关节，官方模拟器配置和本策略均使用 31 个具名关节；真机是否开放这 31 个关节仍须核实。

服务器运行目录 `/home/2025-Long.xh/HHD/data/supermimic/logs/official_x2_sim_20261030_r1/`。项目源码是 `93f598e` 的隔离副本，加之后续记录在 Git 的 `120ddf6` 和本记录提交中的脚本修改；原始官方包未覆盖。ROS 限定 `ROS_DOMAIN_ID=179`、`ROS_LOCALHOST_ONLY=1`，CycloneDDS；网络插件绑定 `127.0.0.1:51879`。安装到运行目录的 Ubuntu / ROS 镜像 deb 包及 SHA-256 保存在 `debs/`、`dependency-sha256.txt`，未修改系统安装。Fast DDS 首次尝试在官方插件加载时崩溃（`gdb.log`），改用官方推荐的 CycloneDDS 后启动。仿真初始化使用 `initial-pose.json` 中的站姿末帧（配置副本修改）；每次运行只在开始时初始化，运行中不重置。

这次启动器与环境分别保存在运行目录的 `start-sim.sh`、`ros-env.sh`；`all-schedule.json` 为自动测试输入，`source-integration/scripts/deploy/` 保留了实际运行版本。消息桥和命令桥使用 ROS 的系统 Python 3.10，推理使用项目 Python 3.12，通过本机 UDP 19179/19180 交换数据。启动顺序是先启动两座桥，再启动策略并等待 `policy ready for simulator`，最后启动仿真；每次重新启动仿真也要重启状态桥以清空旧数据。每轮使用新的输出目录。任务结束后这些测试进程已关闭。

## 实现及证据

- `skill_goal.py` 从独立 FK、五个参考动作、站姿及阶段队列生成 729 维目标。回放先前物理轨迹：前进和小跑各 1400 帧，未来窗口最大绝对差分别 `1.20e-7` 和 `2.39e-7`，锚点位置最大差分别 `7.21e-6` 和 `3.04e-5` 米。只证明记录输入的计算对齐，不证明实机估计。
- `official_sim_state.py` 接收四组关节、骨盆 IMU 和仿真 odometry，转发到本地 UDP；`official_sim_command.py` 以官方 ROS 类型向本机仿真发送 31 关节位置目标，理论定时 500 Hz。目标来自 `official_sim_policy.py` 的 50 Hz CPU TorchScript 推理；失联降阻尼逻辑仅适合此仿真。实际 500 Hz 发布间隔没有测量，进程死亡亦不能保证降阻尼，绝不是硬件看门狗。策略使用训练的 KP/KD 及 scale，尚未经过任何实机适配。
- 按键页和脚本均通过同一策略进程的技能选择器。浏览器实际按住 W、Shift+W、S、A、D 并松开；`keyboard-test/result.json`：2696 个推理帧、53.94 秒、未触发高度/倾斜终止、无中途重置。记录的模式顺序为 stand、walk、stand、jog、stand、backward、stand、left、right、stand；连续快速切换时仍会走完已排队的制动段，后退键短按期间曾继续向前。
- `all-test2/result.json` 和 `frames.jsonl`：按计划连续运行五动作，2687 个推理帧，53.81 秒，无中途重置、无高度/倾斜终止。W 约 7 秒前进位移 1.57 米，小跑约 7 秒前进位移 6.07 米，后退约 4 秒位移 0.96 米；左转约 31°、右转约 -36°。机器人根高度最低 0.585 米。以上是单次试验，松键、停止和切换并未覆盖多个时相。
- 小跑松键后 1 秒水平位移约 0.64 米、3.9 秒约 0.81 米；在第一个 1 秒内参考前向速度积分约 0.39 米，显示计划轨迹本身包含继续前移，但不能由此单独归因于参考。前进松键后 3.9 秒约 0.34 米。独立站姿运行 22.63 秒位移约 0.22 米；不能将未倒视作站稳。
- 本轮策略周期均值约 20 ms，99 分位约 25 ms，最大约 82 ms；时序仍不满足可用于实时控制的结论。脚部接触力、碰撞质量、延迟注入、控制权交接及真正的看门狗均未验收。
- 官方窗口原始录屏中机器人走出相机；`all-test2-replay.mp4` 用记录的官方仿真关节及骨盆姿态和官方模型重新渲染相机跟随画面，非原始窗口实时录像，不是另一次物理仿真。轨迹采样时序有抖动，回放固定 25 FPS。

## 门槛

当前结果说明单次官方仿真中通信、推理、按键和五动作链路可运行，不说明策略已稳定或可上实机。需先定位停步位移、长时漂移和时序抖动，做多起始时相、连续启停、长站立、接触和异常注入评测；再独立验证状态估计、实时发布及硬件看门狗。不得使用仿真 odometry 真值、仿真电机增益或 Python 降阻尼逻辑控制实机。
