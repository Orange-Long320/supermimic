# 转向追赶旧位置的代码修复（2026-11-04）

## 行为变化

修复前，行走/停止产生的累计位置误差会直接带入后续原地转向。
现在 `SkillGoal.goal()` 在新请求左转或右转时，将参考根部 XY 登记为该帧实测根部 XY。
持续同一转向请求不会重复登记，因此水平位置纠偏仍然存在；松键后重新转向、
以及左右方向直接切换会重新登记。只改水平平移，保留累计朝向、根高度、关节参考、
已发布的未来窗口及阶段制动队列。仍须执行的过渡段如果包含参考线速度，
位置目标会照常积分这段位移，不能把这段制动位移描述成已被消除。

`SkillTracker` 采用同一规则，读取仿真根位置后减去环境原点，避免部署与训练仿真
参考生成逻辑不一致。无锚点策略路径、站立和行走请求不触发该登记。
用户此前要求恢复的站立位置反馈继续保留，未重新启用水平误差置零。

改动前回档点 `bb4c1a0`；实现 checkpoint `1ee7838`。
不改变策略权重、数据、执行器增益、关节输出限制、实机安全门禁或训练算法。
没有启动训练、没有 PPO，没有同步或运行 PC2 控制程序。
