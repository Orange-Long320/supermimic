# Mac 本机键盘仿真（2026-11-04）

## 用户授权与范围

用户反馈服务器画面卡顿，并明确要求“能不能在本机仿真”。本次按该明确授权
在 Mac 上运行本机物理仿真，作为 AGENTS.md 默认只在服务器运行仿真的会话例外。
没有修改仓库全局运行规则，也不因此授权后续本地训练或任何实机输出。

使用官方 X2 Ultra `scene.xml`、`x2.xml` 和网格，MuJoCo 3.16.0 物理，
原 11500 NumPy FP32 策略、同一选定参考和本次转向入口登记修复。
策略/参考使用本机 CPU，窗口与按键使用本机 GLFW，完全不经过 SSH 视频或 ROS。
不是官方 Linux ROS 插件的跨平台复现，不是实机状态估计或部署验收。

## 控制与绘制

`scripts/evaluation/play_native_keyboard.py` 使用 profile 的关节默认值、动作缩放和
KP/KD。策略输入仍为 10 帧、按观测项排列的 990 维历史，目标为 729 维。
目标不额外作位置范围裁剪；每个 1 ms 物理子步按官方模型电机力矩范围限幅，
20 个子步对应一次 50 Hz 策略更新。使用骨盆模拟姿态/角速度及根位置真值，
初版没有 IMU 位置双积分、噪声注入或真实机器人接口。
用户随后要求不依赖特权状态，当前默认已改为下述 IMU 模式。

物理与策略独占一个工作线程的 `MjData`；主线程保留原 Retina 画质，使用另一份
`MjData` 绘制，锁只保护位置、速度、时刻快照复制。模型编译后不在运行中修改。
按键在主窗口读取，失去焦点则请求站立。主线程图形实现遵循
[MuJoCo 官方绘制接口](https://mujoco.readthedocs.io/en/latest/programming/rendering.html)。

## 使用

```bash
bash scripts/deploy/run_x2_local_keyboard.sh
```

在仿真窗口按住 `W/S` 前后走、`A/D` 左右转、`Shift+W` 小跑，松键站立。
`Space` 暂停/继续，`R` 手动重置，`Esc` 或关闭窗口退出，滚轮缩放视角。
失败时冻结物理并显示提示，需手动 `R` 重置；手动重置会记入日志，
不能把重置后的多个片段当成一次无重置动作成功。

## 用户要求的非真值 IMU 模式

用户明确要求“在这里也用陀螺仪算，不要依赖特权数据”。当前默认
`--state-source imu`，输入仅为 `imu_0` 的原始 `gyro`、`accelerometer` 与关节
编码器位置/速度；不读取 `framequat`、`framepos`、`velocimeter`、根姿态或根速度
作为策略/目标/停止判断的输入。根真值只用于绘制和离线评分。
显式 `--state-source truth-diagnostic` 仅保留作比较，默认和本轮测试均未启用。

- 模拟传感器每 2 ms 采样一次（500 Hz），策略仍为 50 Hz。
  每次采样先重算该时刻传感器，避免将上一步传感器值标成下一步时刻。
- 姿态由陀螺仪积分，满足 IMU 静止阈值并保持 0.2 秒时，以加速度进行重力调平。
  偏航起点为任意本地零方向，初始姿态单位旋转和初始速度零均为先验假设，
  没有从模拟器恢复；未通过独立静止标定。静止阈值本身不能证明静止。
- 水平位置/速度使用现有实机生产器的 4 状态 Kalman、右端积分、IMU-only ZUPT
  方程与阈值。姿态融合是本次本地实现，**不同于真实 IMU 固件提供的姿态**；
  不能将结果宣称为完整实机算法的等价复现。未修改 PC2 状态生产器。
- 已知骨盆 IMU 安装偏移用于杆臂位置转换。高度通过独立 FK 模型、编码器和
  估计姿态，取最低踝关节高度加声明的 0.05 m 足底偏移；假设平地支撑，
  不使用实际接触状态或地面真值，不适合用来验证飞行中的高度。
- 数学回归测试 7 项通过，覆盖陀螺仪偏航积分、恒加速度积分、静止 ZUPT 和
  重复/倒退/间断/非有限时间戳。新模块为 `deploy/imu_dead_reckoning.py`。
- 启动器每次更新专用推理源码副本，防止本机仍导入旧估计器。

400 帧，4001 个 IMU 样本，无重置/估计高度倾斜终止。

1697 帧，全为站立请求、无重置，16971 个 IMU 样本，813 次 ZUPT。
实测周期约 49.994 Hz，原 Retina 2200×1640 图形窗口正常运行并随后退出。
末端估计位置约 `[-0.745, 0.310, 0.604] m`，实际根位置约
`[14.585, -1.799, 0.630] m`，水平误差约 **15.475 m**。
这是未通过的位置估计/站立闭环试验；没有高度/倾斜终止不代表站稳或定位正确。
真值仅在运行结束后参与该误差计算，没有回灌估计器或策略。

当前结果暴露新估计链的严重偏差，不是实机精度结论。
初始姿态/速度假设、IMU-only 静止判定、重力调平与实际固件差异尚待细分归因，
不能直接归结为“陀螺仪坏了”，也不通过隐藏漂移或重新引入真值来使结果好看。
后续运行额外保留 500 Hz 原始 `imu.jsonl` 和每策略帧编码器值，供重放排查。

每次使用新的 `outputs/x2_local_keyboard_时间戳/`，保留帧记录、首帧截图和
退出时的 `result.json`。运行环境未就绪时启动脚本直接报错，不自动安装或覆盖。
