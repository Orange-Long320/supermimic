# X2 无地图状态估计探索（2026-10-31）

用户明确表示没有地图且希望无地图使用策略。本记录只涉及只读检查和服务器仿真轨迹事后分析；没有启动建图、重定位或实机电机控制。

## PC2 只读结果

在 `lxh` 容器使用一个 ROS 节点观察 20 秒：胯部 IMU 收到 9845 条，最大接收间隔约 12.2 ms（一次测量，非实时保证）；`/aima/mc/common/state`、`/aima/mc/leg_odometry`、`/pnc/estimate_odom` 和 `/ranger_base_node/odom` 均未收到消息。`/pnc/estimate_odom` 在大部分采样时段可发现 1 个发布者，但仍没有收到消息。另一个 20 秒的单节点发现测试订阅全部发现的 `nav_msgs/msg/Odometry` 话题，8 个话题均未收到样本；QoS 为 BEST_EFFORT/VOLATILE。发现发布者不代表发布了可接收数据，也不能根据这一结果断定某服务被禁用或设备故障。

机器人 SLAM 本地配置把 `/aima/mc/leg_odometry` 作为输入，但该话题在此时段没有发现发布者。官方文档的 `/aima/mc/common/state` 包含运动模式与速度边界等状态，不能把其中命令边界假定为已测机体速度。需要核对设备当前状态、接口版本、QoS 与运控侧是否开放无地图的位姿/速度输出。记录见 `outputs/x2_mapfree_state_20261031_r1/`，容器的对应 JSON 也已保存。

## 不依赖地图的离线初筛

脚本 `scripts/evaluation/eval_mapfree_kinematic_odometry.py` 对已有官方仿真轨迹事后计算：由仿真姿态和关节运动学，将相对高度较低的脚假设为固定支撑，切换使用 1.5 cm 高度迟滞，积分水平位移；然后与仿真骨盆位置真值对比。此方法**没有测量接触或承重**，未估计骨盆高度，也未模拟实机传感器时序、标定或噪声，不接入控制。

- 小跑三次无重置启停（61.87 秒）：三次松键后 4 秒窗口的相对位移误差为 0.225、0.092、0.267 米；全程末端累计误差 2.256 米。
- 直接站姿稳定后 90.00 秒：从稳定段开始重新计误差，末端 0.0117 米。
- 小跑后站姿稳定后 84.25 秒：从稳定段开始重新计误差，末端 0.0412 米。

这些是单条仿真轨迹的运动学初筛，不代表实际机器人的性能。高度最低脚的固定支撑假设在运动和收步中误差过大，不能用于实机。

后续需找到可连续验证的机载相对状态来源及其坐标系、时钟和失效语义；或研发具备可信支撑/惯性融合的状态估计，并在服务器使用足够多动作与支撑时相比较、再做不发布关节命令的机载影子验证。该模型的仿真骨盆真值不能当作实机输入，用户所选策略和参考未更换。
