# 技能阶段：候选与无重置评测（2026-10-30）

## 范围

沿用 X2 Ultra 原资产和五动作跟踪冻结点，不做训练或 PPO。只对前进、循环、制动、收步、站立做探索；没有实现通用键盘阶段调度器。参考使用 `walk.npz` SHA256 `8e7813254aa415246ef1a895bdc89350e2b1c134dab73114e7da55fa8f07dd63`，检查点 `c4ebad3cb5686a3d237591b4400fc32eb1c65d56c5af028ab07a63ede5bb554b`。前者为视频恢复参考，非物理验收通过的参考；后者曾通过单片段早终止检查，不证明启停合格。

## 构造与局限

`prepare_skill_phase_candidate.py` 将原始片段的起步和一个周期复制，循环连接处用 12 帧 Hermite/四元数插值，松键后用 75 帧插值至原片第10帧姿势，末尾保持250帧。制动/收步只是这段插值的前后标记，不是脚接触约束设计，也没有真实减速或落脚来源。根据各完整生成轨迹重新计算速度和身体运动学。三个候选循环端点分别为原始帧123、100、110；循环次数3、1、2。它们同时改变循环接缝和松键时相，并非严格控制变量的时相对照。

`audit_skill_candidate.py` 在原模型上测量碰撞几何高度、关节限位和速度。候选123的制动/收步最大硬限位超出0.0274/0.0160 rad，候选100为0.1884/0.1568 rad，候选110为约0.000004 rad。三个候选的两脚几何都在整个站立参考段高于模型地面2 cm以上；地面坐标及几何映射尚需交叉核验，这项检查不等同于物理接触力或支撑判定。三者均未经过接触连续性、动力学可行性验收，不可作正式训练输入。

`eval_skill_phase_candidate.py` 是预先生成参考的实验入口，不改共享训练或键盘控制。第一步初始化后不重置；松键前窗口读继续行走分支，松键后读停止分支，保持 checkpoint 所需的 anchor 特征；这样不会提前看到未来松键信息。环境保留根高、倾斜等原始终止检查并在第一次触发时停止；未改变状态或施加辅助力。松键会使预测窗口改变，不保证窗口时间连续。比较松键前后对同一未来时刻的9帧目标特征，RMS变化分别约0.382、0.731、0.430（特征混合不同单位，作为突变诊断，不作物理误差）。尚未达到要求的连续窗口标准。
