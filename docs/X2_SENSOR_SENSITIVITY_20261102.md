# X2 骨盆估计器：传感器误差敏感性（2026-11-02）

本轮仅服务器 CPU 离线回放及一场隔离物理仿真；没有连接机器人、部署、实机命令或训练。**下列误差幅度均为假设，不是实机传感器标定值，也不是实机精度预测。** 回放估计器使用骨盆 IMU、腿关节与假设平地支撑，不注入 odom 真值；odom 只用于事后评分。未知滑移、未知地形、安装与传感器实际误差仍需独立测量。

## 输入、方法和边界

服务器插桩 XML 中 `imu_0` 姿态为 MuJoCo `framequat`、声明 noise=0；gyro 和 accelerometer 各声明 noise=0.001。实际私有二进制发布器是否以什么机制应用这些 XML 噪声，及 header 与物理采样步关系尚未直接证实。回放在已有记录之上施加额外假设，不假装原数据无噪声。姿态来源是外部提供的仿真朝向，未以 gyro 积分姿态；gyro 偏置实验因此**不是六轴完整惯导**的偏置鲁棒性。

在同一记录上每次只改变一个条件：世界系左乘姿态输出误差不旋转原始 body 传感器；安装旋转误差只改变估计器假定外参；关节零位只改变 q、尺度同时改变 q/qd；加速度白噪声为独立逐样本附加高斯；5 ms 关节错位模拟旧关节值被错误标记为较新的时刻。固定 yaw 保留原世界坐标，只作位置起点对齐，没有拟合方向。纯固定 1° yaw 的不变性检查：两变体 2476 输出时间戳和支撑计数完全相同，基线位置/速度绕 Z 旋转后的最大残差分别 2.95e−14 m/7.71e−16 m/s。

回放复用生产者的右端点积分、支撑几何、1 cm/0.2 m/s 双脚一致性、40 ms 持时和 100 ms 停发，但不模拟 ROS 执行器、DDS、四路关节匹配或墙钟排队。53 秒无误差回放 XY/Z 位置 RMSE 0.0294/0.00098 m，和该记录真实 ROS 对照 0.0284/0.00099 m 接近；覆盖与时间调度不相同，不能作为端到端等价证明。速度真值为 odom 位置 100 ms 中心差分，峰值不等于已确认瞬时误差。

## 完整性故障，不参与正常误差排名

- 给 IMU header 增加独立均匀 ±0.5 ms 人为误差（样本值本身不变）可能制造回退，不能等同网络接收调度抖动。168 秒录制输入中，一对原始 header 间隔 0.165 ms 被扰动为 −0.164 ms，在 8.248 s 触发非递增时间戳拒绝；只覆盖约 4.8%，不按短窗口 RMSE 与完整结果排名。
- 连续删除 18 条 IMU 后形成 38.13 ms 间隔，在 15.037 s 触发原 >30 ms 门限、停止估计；只覆盖约 8.8%，没有跨缺口伪造状态。

`r3_long/common-window.json` 的早期脚本将所有时间戳违规统称 `imu_timestamp_gap`；`r5_timing` 用同源输入、同种子重跑并区分，明确第一项是时间戳回退、第二项是间隔超限。两项均已从共同窗表排除。回放自身曾把无输出评分 failure 覆盖为 None，已修正并增加服务器回归；这是评测脚本修复，不是实机估计精度改进。首轮 r1 的 SciPy yaw 漂移维度错误与日志保留。

## 真实物理斜面小负载验证

私有 scene 只将 MuJoCo 地面 plane 绕 Y 转动假设的 0.5°；x2 XML 与基准 SHA 一致，编译法向 `[0.00872654,0,0.99996192]`、重力 `[0,0,-9.81]` m/s²、步长 1 ms。其余策略和动力学参数未改。单支撑生产者加原生 bag，策略 1404 帧、28.10 s 控制时间、failure=null；这不构成物理动作或实机验收。

29.80 s 共同评分窗、98.86% 有效网格，估计器仍错误假设水平平地：XY/Z 位置 RMSE 0.0178/0.0293 m，XY/Z 速度 RMSE 0.0230/0.0222 m/s；最大 XY/Z 位置误差 0.0335/0.0462 m，末端 Z +0.0427 m，最大输出间隔 80 ms。先前平地参考 Z RMSE 约 0.001 m，但与此不是同一条物理轨迹，不能作严格单变量同轨迹差值。

事后使用 odom 做机理诊断：末端 X 位移 4.712 m 对应 tan(0.5°)×ΔX 约 0.0411 m，Z 误差与该量相关系数 0.9991、残差 RMSE 0.000945 m。真值未用于支撑选择或估计修正。结果证实此条件下水平地面高度模型对斜地失效；没有凭真值拟合坡度或将坡度写入生产者。没有物理滑移或其他地形实验，不能外推。
