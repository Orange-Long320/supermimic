# 小跑收步双脚平行候选

用户指出小跑收步后两脚和站立不自然。检查先前官方仿真末段，实际双脚相对骨盆航向约 +20° / -20°；静止参考自身约 +19.5° / -15.5°，两脚存在约 35° 夹角。原参考以用户此前选定的前进动作第一帧为站姿。**本轮先误将用户的“平齐”理解为脚尖方向平行，制作了下面的对照候选；用户随后澄清是左右脚尖前后平齐，不能把此对照当作其要求。**

服务器独立运行目录 `/home/2025-Long.xh/HHD/data/supermimic/logs/jog_parallel_stance_20261031_r1`。使用官方 X2 Ultra 仿真模型和已训练的 `ckpt_0011500.pt` 导出模型，没有重新训练。`stance/pose.npz` 从原站姿出发，只调整双腿及腰部关节并重置躯干的横滚/俯仰，保留上肢姿态。官方模型几何测得双脚 yaw 均为 0°，球体脚底最低点在地面，重心投影位于球心形成的凸包内约 9.9 厘米。这里的凸包只是几何近似，没有证明接触力或动态稳定。

基于新站姿生成了五条单独的收步参考（`reference/dataset/`，原数据保留）。参考动画 `jog-stop-reference.mp4` 只显示关节和根部位置，不是策略执行。小跑制动参考运动学检查显示最低脚部间距约 -7 毫米，用户可见的视频并不说明其接触合格。

随后以独立数据集 `grounded-candidate/` 修正小跑制动阶段的根部高度，末端站姿完全不变，最多抬高 6.01 毫米；训练模型几何中制动最小脚间距变为 -1.00/-0.37 毫米，离散根高度二阶差最大 3.55 毫米/帧。这是运动学修正，未证明真实受力或自然性，仍需官方仿真对照。
