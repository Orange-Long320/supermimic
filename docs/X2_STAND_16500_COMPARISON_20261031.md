训练使用五运动技能、五条原收步及新增站立参考，从 11500 继续 5000 次向量环境迭代；最终 `ckpt_latest.pt` 内部 iteration 16500、updates 6552、SHA256 `fc7fb197a82f6462d054a6368a11c3bf6a99ac8adea928b422fee2e048ff4b0c`。使用世界模型与可微想象，世界模型及策略启用编译；整卡记录峰值 6808 MiB、PyTorch 保留峰值 5064 MiB、正常结束。服务器隔离评测目录 `logs/six_stand_16500_compare_20261031_r1/`：导出模型、哈希、输入配置、测试、完整日志与轨迹均保留；导出单组输入最大误差为 0，9 项程序测试通过，不代表实机验证。

新、旧权重在同一官方仿真、参考库、初始化和计划下各执行一次，依次覆盖五技能、各三次不同持续时间松键及末尾长站立；过程都没有重置或触发高度/倾斜终止，未来窗口重叠误差均为 0。新旧每次轨迹状态不是完全一致，步态时相亦可能有细微差异；这是一组顺序对照，不是多随机种子统计。

PC2 当前不可连接，机器人 SDK 1.1.5、关节零点与方向、IMU 坐标和机载骨盆状态估计均未核验；底层电机控制权移交、独立看门狗和机载实时性也未验证。仿真 odometry 真值和仿真增益不能用于判断可直接实机部署。

电脑到服务器经 SSH 本地转发的独立仿真 `keyboard/`：通过真实 HTTP 心跳顺序选择五种技能，释放及最后一次小跑时中断心跳并恢复；另用 in-app 浏览器实际按住并松开 W/S/A/D 与 Shift+W（与自动心跳测试为同一无重置轨迹的不同时间段）。实际控制记录 119.53 秒、无重置、无高度/倾斜终止、未来窗口重叠误差 0。持续前进 12 秒，在按键初期 1–5 秒与后期 6–10 秒沿初始骨盆朝向的平均速度分别为 0.249 和 0.346 m/s；持续小跑对应 0.954 和 1.050 m/s。这是一次轨迹的区间均速，不能代替多次闭环评测。小跑 12 秒后松键约 4.08 秒位移 0.937 m，松键后仍明显前移。心跳中断时请求的小跑持续约 3.40 秒，随后自动进入站立模式，包含 0.5 秒超时；这只是仿真控制器中的技能指令超时，并非电机级断连保护。输入过程的 HTTP 客户端日志与时间戳保存在服务器运行根目录 `keyboard-http.log`，实际模式和轨迹见 `keyboard-summary.json` 与 `keyboard/policy/`。

单独的 `focus/` 实验尝试在按 W 期间打开另一个后台浏览器页，记录表明从 walk 到 stand 恰好持续约 4.00 秒，即直到模拟按键结束；因为后台页打开不一定使前页真正失焦，不能把这个测试作为失焦保护通过或失败的证据。浏览器真正失焦事件及真实电脑网络断连的端到端行为仍待验证。
