## 物理语义与时间限制

原 `imu_0` 轴与 pelvis 对齐，位移 `[0.0239465,-0.000228682,0.04171]` m；映射到名称含 `torso` 的话题。XML 定义 framequat、gyro 和 accelerometer，按 MuJoCo 语义，姿态为传感器相对世界的朝向，角速度和含重力的比力以传感器局部轴表达。与 odometry 姿态同 header 插值比较，角误差中位 0.000052 rad、P95 0.000415 rad。用 odometry 20 ms 中心姿态差分估算角速度，按局部坐标比较误差中位 0.00777、P95 0.0408 rad/s；按世界坐标比较中位 0.0621、P95 0.920 rad/s。差分及 odometry 的同步误差未剔除。

骨盆 IMU header 间隔中位 2.000 ms，P95 2.007 ms，最大 4.238 ms，超过 3 ms 两次。header 与同主机接收墙钟之间年龄中位 0.755 ms、P99 2.384 ms、最大 15.66 ms；这是两时钟数值差，不证明 header 是传感器物理采样时刻。官方发布器是二进制，尚未建立 header 与 MuJoCo 物理步的精确对应，也未独立证明消息各字段同一步；以上一致性不是严格时间标定。

## 实际生产者结果

优化了同步匹配：对各组历史从新到旧查找首个因果样本，避免反复生成完整候选列表；增加回调、发布工作耗时和 IMU header/接收年龄统计。该次骨盆生产者处理 27004 条 IMU、173415 条四组关节回调、输出 2679 包，invalid=0、同步跳过 134；生命周期包含启动/结束，age/missing 跳过 1027，不能直接折算稳态丢包。IMU 回调 P50/P99/最大 0.129/0.222/0.791 ms，关节回调 0.0147/0.0284/0.105 ms，成功发布工作 0.828/1.250/2.190 ms。选中 IMU 的回调后年龄最大 14.3 ms。胸部生产者 26993 条 IMU、输出 2680 包，IMU 接收年龄 P99/最大 20.29/40.18 ms，成功发布工作 P99 1.67 ms。

此前 r3 原速负载严重积压；本次无相同量级的年龄，但生产者代码、运行条件和轨迹均不同，不能只凭两次比较证明查找优化是根因或积压已完全解决。骨盆 IMU 两次 >3 ms 的间隔说明存在缺口，但无法从单接收者区分源端、传输和接收端丢样。关节记录器每组仅约 36196 条、间隔 P99 3 ms、最大约 45 ms，远低于按 1 kHz 配置推算的采样数；记录器本身与源端损失未隔离。生产者总关节回调数也不足以证明四组均无丢样。下一步需分组序号/独立轻量订阅和发布端插桩，逐段定位丢样并重复满速负载；不能将发布频率配置等同于收到频率。

## 同轨迹误差与初始化

共同窗口 53.81 s，估计与 odom 位移在窗口起点对齐，速度真值由位置 100 ms 中心差分取得，数值见 `comparison.json`。评分窗口开始处，骨盆真值速度 `[0.0584,-0.000057,-0.0906]` m/s；之后 3 s 真值速度中位 0.0569、P95 0.1387、最大 0.1921 m/s，位移 0.1338 m。此窗不能作为静止窗。该检查窗从共同输出起点开始，不能代替已完成的独立静止标定；生产者本次明确未请求标定。骨盆估计在共同起点相对真值的速度误差为 `[0.0203,0.000032,0.1744]` m/s，已经包含首输出之前的传播与杆臂转换，不应简单说成物理初速全部等于此误差。

## 真值辅助诊断（不是正常估计）

仅将共同起点真值竖直速度用于一次线性修正，不做后续反馈：骨盆末端竖直误差由 +10.255 m 降至 +0.874 m，竖直位置 RMSE 从 5.763 m 降至 0.378 m；说明本例起点竖直速度误差占主要份额，不提供实际可用初速。

`factors.json` 对同一录制 IMU 离线积分，起始 IMU site 速度取真值、初始位置对齐，无 ZUPT；不同于完整 ROS 生产者。9.81 m/s² 重力及 header 时钟下竖直位置 RMSE 0.418 m、末端 +0.961 m；将积分时钟换为记录器接收时间后为 1.361 m、末端 +3.011 m。把重力假设从 9.81 改为 9.80 的人为敏感性实验为 6.887 m、末端 +15.436 m，**不是测得重力错误**。以整段真值首尾速度拟合的等效世界加速度偏差为 `[0.000678,-0.000239,0.000294]` m/s²，回代后水平/竖直位置 RMSE 0.545/0.232 m；它混合时序、差分、杆臂和噪声等误差，不是已辨识的传感器零偏，也不能在线获得。上述诊断展示贡献与敏感性，不能把它们相加为唯一误差分解。
