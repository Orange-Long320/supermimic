# command_stand 与双脚相位独立实验

2026-10-31，用户选择新增 `command_stand` 和双脚相位输入，做独立训练实验。修改前基线提交为 `337b1f4f0e96e9a8cbb012cb3bffdcda94e446ef`，工作区干净。训练仅使用 SuperMimic 世界模型与可微想象，不使用 PPO。

拟定接口为本体观测历史、三维速度指令、独立站立请求和左右脚相位（sin/cos 编码）。`command_stand=1` 表示请求停止，制动期间仍保持交替相位；实测水平速度低于 0.03 m/s 且转动速度低于 0.05 rad/s 时设为同相并冻结。保持同相的退出阈值为 0.06 m/s、0.10 rad/s；重新请求运动立即恢复半周期差。阈值及默认 1.2 Hz 时钟均为待验证实验参数，数值相位不等于接触力或真实双支撑。

拟从原五技能跟踪权重 `logs/five_gait_stops_5h_20261030_r2/train/ckpt_0011500.pt` 初始化世界模型与教师，使用独立六技能库 `logs/six_skill_stand_20261031_r1/dataset`，保留五种运动、停止过渡和站立。新命令编码器先从真实教师轨迹学习，再通过冻结世界模型的可微想象更新；原 motion 编码器和共享 decoder 保持冻结。教师采集不是新接口闭环验收，必须另做新接口的连续启停评测。

首次资源检查：四张 3090 均有其他用户计算进程，未启动 GPU 实验，也未停止任何进程。代码、训练、容量测量、闭环结果均待后续记录。
