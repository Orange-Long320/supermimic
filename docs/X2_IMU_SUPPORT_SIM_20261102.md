# X2 IMU 三维初始化与支撑速度实验（2026-11-02）

仅服务器仿真，未连接机器人。**本记录不构成实机状态估计或控制验收。** 纯 IMU 不能观察恒定速度，运动中零初速启动会产生随时间增长的位置误差。原先评分窗起点的速度误差还包括输出前传播与杆臂，不应全部解释为物理初速。

生产者现在默认拒绝无速度观测的启动；`--allow-unobserved-initial-velocity` 是仅用于诊断的旧行为，显式零速假设。三轴传感器系加速度零偏的静态标定要求 `--init-bias-seconds` 与 `--assume-initial-rest`；标定结果依赖真实静止、重力和姿态准确，IMU 幅值检查不能证明静止或区分倾角误差与偏置。原 IMU-only 水平 ZUPT 默认关闭，`--imu-only-zupt` 仅为实验对照。旧调用若未显式指定初始化方式将拒绝启动。重力读取验证：官方插桩 XML 在 MuJoCo 中为 `[0,0,-9.81]` m/s²，步长 1 ms；不是根据轨迹拟合。默认积分保留右端点，梯形积分显式可选。

`--sim-only --sim-support-xml <X2 XML>` 是仅本机隔离仿真的实验模式，要求 localhost-only、128–232 domain、隔离 state port、指定骨盆 IMU 安装位姿。它假设平地且最低碰撞球与地面瞬时无滑动，使用实际碰撞球底点及完整旋转速度求支撑速度，硬替换三维速度，不是接触力传感器或卡尔曼融合。两脚接近同高（<1 cm）且两足速度假设相差 >0.2 m/s 时拒绝；切换支撑侧后等待 40 ms。未有观测前不输出；超过 100 ms 无更新不输出。阈值是探索性的物理假设，未做多地形泛化。有限 128 样本队列等待关节 header 越过 IMU 时间，再选取因果关节；超过 10 ms 关节外推门限仍拒绝，队列等待超 50 ms 或溢出则报错停止，不跨缺样继续积分。

## 基线诊断与离线约束

旧录制轨迹的真值辅助初速度消融：以 odom 一次性提供 IMU site 初速，无后续反馈，53.81 秒右端点竖直 RMSE 0.383 m、末端 +0.884 m；梯形 0.418 m、+0.961 m。此例数值积分方式差异远小于无观测初速漂移，梯形并未证明精度改善。此前真值等效重力/偏置拟合只供诊断，不能用于正常运行。

两段实际 ROS 数据离线重放，估计不读取 odom、最低球默认为已支撑；odom 仅评分。第一段 / 第二段分别：XY 位置 RMSE 0.0223 / 0.0221 m，Z RMSE 0.1267 / 0.1227 m；XY 速度 RMSE 0.0160 / 0.0194 m/s，Z 速度 RMSE 0.0273 / 0.0274 m/s。第二段 Z 末端 -0.207 m、最大绝对误差 0.211 m，瞬时 XY/Z 速度最大误差 0.321/0.722 m/s。两段轨迹近似同一动作序列，并非独立地形泛化。仅用真值高度挑选近地球的单独 oracle 对照不是正常估计；附近球不保证存在接触力或不滑移。球底点解析 FK 与官方 MuJoCo 雅可比 200 个随机状态对照，高度/速度最大残差分别 4.44e-16 m / 2.08e-15 m/s。

条件标定正例为私有 XML 人工焊接固定：约 3 秒标定窗 odom 最大位移 3.53e-6 m、最大速度 3.57e-5 m/s，真实 ROS 生产者接受标定并输出 245 包。三轴偏置、运动窗拒绝、默认拒绝无初速的三项回归通过。焊接静态不等于自然站立。

## 采样与记录链

独立轻量订阅者与记录器按 header 在约 38.6 秒共同窗口逐条比较：四组关节探针每组约 38338–38368 条，记录器每组约 26013–26014 条；约 12455–12472 个每组 header 被探针收到而记录器没有。每组反向约 117–139 个仅记录器收到。IMU 探针 19254 个 header 均被记录器收到，记录器另有 12 个。可确定记录器接收/处理/写入路径存在显著缺失；不能据此认定发布端没有丢样，也不能区分共同缺口由发布调度、DDS 或两个接收端共同丢失造成。官方二进制 header 与物理采样步及字段同一步的精确对应仍未证实，不能将 header 间隔异常归因于单一环节。

## 实际 ROS 支撑速度对照

结果是这条轨迹有效网格上的评测，不代表连续可靠或其他轨迹泛化。支撑版 2744 包、2158 次支撑更新、346 次持时拒绝、191 次双足不一致拒绝；71 个发布机会因超过 100 ms 未更新被拒。该运行未逐次记录拒绝的时间，故无法精确恢复最长连续拒绝时长；最长输出间隔为 162 ms；不能断言间隔全部由观测拒绝造成，也不能据此精确恢复连续拒绝时长。后续源码增加了逐次拒绝事件记录，但这项记录未在 r6 运行。support 队列等待 P99/最大 21.78/29.35 ms，因果关节 header lag P99/最大 2.01/8.02 ms，超时与溢出均零；输出 age 最大 29.14 ms。IMU 共收到 28479 条，接收年龄 P99/最大 6.88/17.85 ms，header 最大间隔 6.00 ms，超过 3 ms 39 次。时间戳物理语义限制同前；无输出窗口不可用插值补作观测。

r4 实时失败时在 IMU 到达回调中立刻取关节，因果 leg header 通常落后约 19.9 ms，2543 次超出 10 ms 限制，仅 2 次接触假设更新；其结果不可评分。r6 等待后续 leg 到达而保持 IMU 顺序，未放宽时限，取得上述结果。旧 IMU 自身静止规则虽在 r2 水平误差更低，但没有独立静止证据，因此只保留显式对照选项。
