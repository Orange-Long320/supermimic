# X2 IMU 融合的接触与滑动初筛（2026-10-31）

## 范围与方法

沿用用户选定的 11500 步模型和双脚朝向接近平行参考。全部估计仅在服务器离线消费官方仿真器实际发布的 IMU、关节位置和速度；仿真骨盆位置仅用于事后衡量误差，并未送入估计器。不是闭环运行，不是实机采样或控制；轨迹按时间离线插值到 50 Hz，插值非因果。实际足底力、接触和打滑标签不可用。

基线是上次的 IMU 加速度积分加卡尔曼滤波，利用最低脚踝位置的有限差分推断支撑脚。改进版本使用脚部碰撞球几何推测最低接触点，用雅可比矩阵、关节速度和 IMU 角速度计算该点相对基座的运动；支撑脚切换最短间隔 0.2 秒。附加的候选门控对运动学测量与预测残差进行检验；双脚给出的速度差异大时降低更新权重。它只代表**不一致风险**，不是已验证的接触或打滑分类器。`tests/test_imu_contact_jacobian.py` 在服务器通过，核对雅可比速度与有限差分一致。

候选在此前约 59 秒五动作轨迹上确定，不依据以下独立轨迹再调整。完整数据和日志在服务器 `/home/2025-Long.xh/HHD/data/supermimic/logs/imu_fusion_holdout_20261031_r2/`；采集来源提交 `e671f69`，离线分析提交 `9f5b20d`。机载机器人未执行本实验。

## 独立多时相对照

约 100.58 秒控制轨迹，无重置、无既定高度/姿态终止；五个动作各松键两次（共 10 次），每次按用户指定 11500 步策略生成。轨迹来自 ROS 仿真 IMU 和关节消息，记录采集及估计代码、配置、模型和参考校验值。一次连续轨迹不等于多个独立初态或泛化验证；两次小跑的选定参考帧为 88 和 90，间隔仅两帧，不能认为覆盖了完整小跑步态周期。

运动段起点重新计算的相对位移误差：门控版本的两次小跑终点为 3.6 和 4.0 cm，原方法为 20.9 和 29.7 cm；这并未重置估计器本身。其余动作的各运动段终点误差为 0.3～3.3 cm。不同阶段起点计算的位移误差不能相加，也不能和全程末端误差直接比较。

存在取舍：第二次小跑松键后 4 秒端点，门控版本误差约 5.0 cm，而没有门控的几何接触点版本约 1.1 cm；该次 4.48 秒站立阶段内的最大相对误差分别为约 6.1 和 2.2 cm。不能称门控在所有时相均改进。

以仿真真值和运动学离线计算的脚部近地几何和速度仅作为代理；门控版本选中脚几何近地比例 100%，近地速度 P95 约 0.031 m/s。该计算不能确定脚是否实际承重或真的发生滑动，无法计算接触判断或打滑识别的准确率。`holdout-baseline.json`、`holdout-jacobian.json`、`holdout-robust.json` 和轨迹日程已复制至本地 `outputs/x2_imu_contact_slip_20261031_r1/`。

下一步应补充具有独立接触/力或可信摩擦真值的仿真、滑移和腾空扰动，以及更多不同初态和步态时相；消除离线非因果插值后再做闭环。实际机器人上的 IMU、关节标定、同步、延迟、机载计算和无关节命令影子估计也均需验证。当前结果不足以接入真机电机控制。
