# X2 楼梯项目

目标：仿真中仅双脚支撑，适应不同尺寸楼梯，从平地起步、完整登顶并稳定停止。
路线：地形观测 → ACP 式双脚接触规划 → SuperMimic 世界模型和可微想象策略更新。
不启动 PPO，不包含实机运动授权。

开发工作区：`../supermimic-stairs`，分支 `codex/x2-stairs`。
当前管理目录仅保留项目索引；实际实现和后续实验记录在楼梯工作区推进。

新代码：`src/supermimic_stairs/`；入口：`scripts/stairs/`；配置：`configs/stairs/`；
测试：`tests/stairs/`。公共 `supermimic` 源码使用本工作区固定版本，禁止导入键盘工作区。

详细方案和现存缺口见 [初始实验记录](../../docs/X2_ACP_STAIRS_20261104.md)。
当前没有已完成的 ACP 接口、上楼策略或训练验收。历史平地/攀爬脚本不是楼梯入口。

阶段顺序：场景与示范 → 接触条件控制器 → 接触规划器 → 多尺寸训练 → 独立完整任务评测。
环境、数据、源码发布包及输出均使用 `stairs` 名称空间，不与键盘共用可变目录。
